# Student-performance-analysis-ml
A complete machine learning project for analyzing student habits and predicting exam performance using Linear Regression and Pass/Fail classification. Includes EDA, data preprocessing, model evaluation, and performance insights.
# Student Performance Machine Learning

This project uses Exploratory Data Analysis (EDA) and Machine Learning to analyze student habits and predict academic performance.

## Project Features

* Exploratory Data Analysis (EDA)
* Missing value and outlier analysis
* Correlation and feature relationship analysis
* Linear Regression for predicting exam scores
* Logistic Regression for Pass/Fail classification
* Model evaluation and performance comparison

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook / Google Colab

## Models

* **Linear Regression** – Predicts student exam scores.
* **Logistic Regression** – Classifies students as Pass or Fail using a 50-mark threshold.

## Dataset

The dataset contains information about student habits, including study hours, attendance, sleep, social media usage, exercise, mental health, and exam performance.
